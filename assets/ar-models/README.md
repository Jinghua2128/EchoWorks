# AR character poses

Each transparent WebP matches one physical card with the same filename stem.

- `REAL_R`: torch / spotlight pose
- `REAL_E`: balanced scale pose
- `REAL_A`: compass / guidance pose
- `REAL_L`: folder / linking pose
- `CARE_C`: seated breathing pose
- `CARE_A`: magnifying-glass pose
- `CARE_R`: collaborative fist-bump pose
- `CARE_E`: active step / execution pose

The assets are 1024 by 1536 RGBA WebPs. Keep replacement characters fully visible, unflipped, and on transparent backgrounds.
