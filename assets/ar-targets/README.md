# MindAR target bundle

`echoworks-cards.mind` was compiled locally with MindAR 1.2.5 from the physical card files in `assets/ar-cards`.

Target indexes are fixed:

0. `REAL_R`
1. `REAL_E`
2. `REAL_A`
3. `REAL_L`
4. `CARE_C`
5. `CARE_A`
6. `CARE_R`
7. `CARE_E`

If a card image or this order changes, recompile the entire target bundle and update `assets/data/ar-cards.json` in the same release.
